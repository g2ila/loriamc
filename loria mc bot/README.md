# 🤖 بوت ديسكورد للتحكم بسيرفر اتيرنوس (Aternos Minecraft Bot)

بوت ديسكورد احترافي ومستقر للتحكم في سيرفر ماينكرافت المستضاف على Aternos باستخدام بايثون وأوامر السلاش (`/`).

---

## 🌟 المميزات
- **/start :** تشغيل السيرفر ومتابعة قائمة الانتظار (Queue) تلقائياً، وإرسال تنبيه في الشات فور اكتمال التشغيل مع الآي بي.
- **/status :** فحص حالة السيرفر، الآي بي، عدد اللاعبين وقائمة المتواجدين والإصدار.
- **/stop :** إيقاف السيرفر (متاح فقط للإدارة).
- **/restart :** إعادة تشغيل السيرفر (متاح فقط للإدارة).
- **التنبيه التلقائي:** البوت يراقب حالة السيرفر في الخلفية ويرسل إشعاراً مع المنشن فور تحول السيرفر إلى `Online`.

---

## 🚀 طريقة التشغيل

1. **تثبيت المتطلبات (Requirements):**
```bash
pip install -r requirements.txt
```

2. **التأكد من إعدادات ملف `.env`:**
الملف يحتوي على:
- `DISCORD_TOKEN`: توكن بوت الديسكورد.
- `ATERNOS_SESSION`: جلسة اتيرنوس (Cookie).
- `ATERNOS_SERVER_NAME`: اسم السيرفر (مثال: `test.aternos.me`).
- `NOTIFICATION_ROLE_ID`: (اختياري) آيدي الرتبة التي سيتم منشنها عند التشغيل.

3. **تشغيل البوت:**
```bash
python bot.py
```
